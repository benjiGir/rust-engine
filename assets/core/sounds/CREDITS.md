# Crédits des sons

Les licences des médias ci-dessous sont indépendantes de celle du code du jeu.
Les originaux ont été sélectionnés, coupés, convertis, filtrés et ajustés en volume.
Les boucles ont reçu un fondu de raccord ; le carillon d'enchantement est un montage
original de plusieurs transpositions d'une cloche enregistrée. Aucun son Minecraft.

[pixelsphere.org](https://pixelsphere.org/)**, morceaux publiés sous CC0 1.0 :

- Jour 1 : [Vaporware](https://opengameart.org/content/calm-piano-1-vaporware).

- Sous terre : [Sirens in Darkness](https://opengameart.org/content/sirens-in-darkness).

Les morceaux complets ont été ajustés à −23 LUFS, avec un plafond de −3 dBTP,
un fondu d'entrée, puis encodés en Vorbis stéréo 44,1 kHz. Les identifiants publics
du jeu sont conservés. Le détail par prise, le nom du fichier amont, les conversions
et les empreintes des sources PCM et OGG se trouvent dans `sources.json` à côté de
ce fichier dans `tools/assetgen/audio/` du dépôt.
